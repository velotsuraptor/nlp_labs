# Labeling Guidelines — UAReviews Category Classification

## Загальне правило
Вибираємо 1 домінуючу категорію (основний намір автора).
Якщо є змішані сигнали:
- якщо текст одночасно питає і скаржиться → зазвичай `Complaint / Dissatisfaction`, якщо головне — негатив/проблема; `Question / Request for Help`, якщо головне — отримати інструкцію/відповідь.
- якщо є порада + негатив → `Suggestion / Idea`, якщо основне — пропозиція; `Complaint / Dissatisfaction`, якщо основне — невдоволення без конкретної пропозиції.

---

## 1) Gratitude / Positive Feedback
**Визначення:** подяка, похвала, позитивна оцінка сервісу/організації/людей.
**Входить:**
- “Дякую, все швидко і професійно.”
- “Супер сервіс, рекомендую.”
- “Дуже задоволена роботою команди.”
**Не входить:**
- “Дякую, що знову нічого не працює.” (іронія → Complaint)
- “Підкажіть, як…?” (Question)
- “Було б добре додати…” (Suggestion)

---

## 2) Complaint / Dissatisfaction
**Визначення:** скарга, невдоволення, опис проблеми з негативною оцінкою.
**Входить:**
- “Жахливе обслуговування, хамство.”
- “Черги, ніхто нічого не пояснює.”
- “Не працює, витратив час дарма.”
**Не входить:**
- нейтральний факт без оцінки (Neutral)
- питання без негативного тону (Question)
- конкретна пропозиція покращення як головна частина (Suggestion)

---

## 3) Question / Request for Help
**Визначення:** запит інформації або допомоги (“як зробити”, “куди звернутися”, “що означає”).
**Входить:**
- “Куди звернутися, щоб…?”
- “Як оформити/відновити…?”
- “Коли буде доступно онлайн…?”
**Не входить:**
- риторичне “чому все так погано?” як скарга (Complaint)
- порада/фіча-реквест (Suggestion)
- подяка/похвала (Gratitude)

---

## 4) Neutral Comment
**Визначення:** нейтральні повідомлення без чіткої подяки/скарги/питання/пропозиції.
**Входить:**
- фактологічний опис без оцінки
- короткі нейтральні репліки без наміру
- повідомлення “для інформації”
**Не входить:**
- будь-яка явна оцінка “добре/погано” (Gratitude/Complaint)
- питання (Question)
- пропозиція (Suggestion)

---

## 5) Suggestion / Idea
**Визначення:** пропозиція покращення, рекомендація, ідея (“додайте”, “зробіть зручніше”, “варто…”).
**Входить:**
- “Було б зручно, якби додали…”
- “Зробіть ще одне місце/вікно/функцію…”
- “Рекомендую відвідувати/використовувати…”
**Не входить:**
- просто негатив без рішення (Complaint)
- запит “як зробити” (Question)
- нейтральний коментар без ідеї (Neutral)
